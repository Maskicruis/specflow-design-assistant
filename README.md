# 规序 SpecFlow · 规范辅助设计工作台

面向工程设计人员的本地多模态 RAG 应用：导入 PDF / Word，按设计阶段检索规范，生成附来源的参考回答，并回到原文复核。**v1.1 已移除知识图谱展示，专注于规范辅助设计。**

## Windows 快速开始

先安装 **Python 3.13（64 位）** 和 **Git**。使用具有仓库权限的 GitHub 账号克隆：

```powershell
git clone https://github.com/Maskicruis/specflow-design-assistant.git
cd specflow-design-assistant
.\安装依赖.cmd
Copy-Item .env.example .env
```

在本机 `.env` 中填写自己的模型密钥，双击 **启动演示.cmd**，打开 <http://127.0.0.1:8765>。进入「模型与连接」，核对服务地址、模型名和密钥变量名；明确允许远程发送资料后才启用远程模型。

**仓库只包含程序，不包含规范原件、解析数据库或密钥。** 新安装的资料库为空。可导入自有文件，或按部署说明迁移旧电脑的资料备份；后者保留已解析内容、历史和收藏，避免重复模型解析。

## 主要功能

| 入口 | 用途 |
|---|---|
| 规范问答 | 按问题或条文编号检索，生成有来源的参考回答 |
| 设计流程 | 站址与规划、总图与间距、道路与竖向、设施与管线、消防与安全、校核与交付 |
| 规范资料库 | PDF / DOCX 导入、原页查看、表格和图示查找 |
| 我的证据夹 | 收藏证据、导出 JSON；回答可另行导出 Markdown |
| 处理任务 | 多模态解析、进度、停止和续跑 |
| 模型与连接 | 配置本机或远程兼容模型服务 |

解析使用 PDF 原生对象、DOCX OOXML 和视觉语言模型，不调用 OCR 引擎。扫描页尚未成功解析时不会进入答案索引。检索采用中文 BM25 和流程/主题标签辅助排序；当前没有神经向量库或独立重排模型。

## 日常维护

- 启动：`启动演示.cmd`；停止：`停止演示.cmd`。
- 备份：`备份资料.cmd`，输出至本机 `work/backups/`，**备份含私人规范，不能上传 GitHub**。
- 更新：`更新程序.cmd`，检查源码修改、停止空闲服务、备份资料，再执行 `git pull --ff-only` 和依赖安装。更新后重新启动。
- 测试：安装 `requirements-dev.txt` 后运行 `python -m pytest tests -q`。所有命令应使用项目虚拟环境中的 Python，详见部署说明。

## 使用边界

这是单机演示应用，没有用户认证和多租户权限。只监听 `127.0.0.1`，不要直接开放到公网或局域网。已索引资料可离线检索；扫描解析和模型综合需要可用模型服务，远程 API 可能计费。

机器解析可能误读表头、数字、单位和脚注。未人工复核页的表格数值不会传给回答模型；引用 ID 检查也不能保证语义正确。设计结论仍须由专业人员核验原文、适用条件及现行版本，报批稿不视为现行依据。

第三方依赖和规范资料各自保留其权利，部署前阅读 [依赖与资料说明](NOTICES.md)。
